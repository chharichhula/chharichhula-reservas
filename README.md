# Chhari Chhula · Reservas

Sitio de reservas de Chhari Chhula, el hada de las uñas: recorrido puerta → portal → exterior → interior del salón y reserva en tres pasos (datos, día y horario, seña).

- Sitio publicado: https://chharichhula.github.io/chharichhula-reservas/
- Servidor (agenda, pagos, cancelaciones): `servidor/` → ver **SERVIDOR.md**
- Operación diaria de Chhari: **GESTION-DE-TURNOS.md**
- Modo mantenimiento: `estado.json` (`"mantenimiento": true`); `?preview` entra igual
- Pruebas: `node servidor/pruebas/run.js` · prueba local completa: `node servidor/pruebas/dev-server.js`
- Diseño aprobado y contrato de pagos: `docs/`
- Versión anterior del sitio: etiqueta `antes-diseno-final`
